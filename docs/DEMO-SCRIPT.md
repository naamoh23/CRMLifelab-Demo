# สคริปต์นำเสนอ (ประมาณ 15 นาที)

เริ่มที่บทบาท **ผู้บริหาร** seed มีลูกค้าสมมติ 24 ราย ยอดรับชำระ 1,002,000 บาท ช่วงกันยายน 2569 หากเคยทดลองตัวเลขจะเปลี่ยนตามข้อมูล ใช้ Settings → จัดการเดโม → คืนค่าข้อมูลตัวอย่าง เมื่อต้องการล้างการทดลองใน browser นี้เท่านั้น

1. **ภาพรวม** — อธิบาย Case → Cash → Certificate ดู KPI/กราฟ/งานวันนี้ คลิกดูรายงาน สลับ Light/Dark และปรับหน้าต่างเล็กเพื่อแสดงเมนูมือถือ
2. **Customer 360** — เปิด ณิชา วัฒนกุล ดูข้อมูล ประวัติขาย การเงิน การเรียน เคส LINE เอกสาร งาน และ Audit ค้นหาชื่อ/Customer ID ข้อมูลทั้งหมดสมมติ
3. **Pipeline/เคส** — ลาก Lead หรือเลือกสถานะ เปิดเคสพร้อม Owner/Due Date เพิ่ม Internal comment ลองปิดโดยไม่มี Resolution เพื่อดู validation
4. **รับชำระ** — การเงิน → รายการชำระและสลิป: `PAY-3013` ศศิธร แสงทอง 12,000 บาท ผู้เสนอพนักงานบัญชี อนุมัติด้วยผู้บริหาร ยอดรวมเพิ่มเป็น 1,014,000 บาท ไม่มีเงินจริง
5. **PEAK** — การเชื่อมต่อ: เห็นงาน `peak:payment:PAY-3013` กด Retry `INV-2609-010` แล้วสถานะสำเร็จและปุ่มซิงก์ซ้ำปิด ดู Customer/Field mapping กดตรวจสถานะ API ต้องแจ้ง Demo
6. **2C2P อัตโนมัติ** — การเงิน → 2C2P และแจ้งเตือน เลือก INV-2609-005 แล้วบันทึก ดู Email/SMS ที่สร้างอัตโนมัติ กดใบเดิมซ้ำเพื่อแสดงการกันซ้ำ เลือก INV-2609-006 ในสถานการณ์ SMS ล้มเหลว แล้ว Retry เฉพาะ SMS อธิบายว่า URL .invalid และ DemoSent เป็นตัวอย่างเท่านั้น
7. **ใบประกาศ** — คอร์สและใบประกาศ → ใบประกาศและการจัดส่ง: `ENR-4002` ธนกฤต สุขเจริญ พร้อมปลดล็อก แต่ `ENR-4005` ยังไม่ครบเกณฑ์ ปลดล็อกแล้วดาวน์โหลด HTML เพื่อพิมพ์ บันทึก Printed → Packed → Tracking/วันที่/ที่อยู่
8. **Marketing/Automation** — ดูเหตุผลการเลือก/ยกเว้นผู้รับ Preview แล้วจำลองส่ง คน Opt-out หรือครบ 3 ครั้ง/สัปดาห์เดโมถูกยกเว้น ทดสอบกฎแล้วดูผลในกิจกรรม/Inbox/Audit
9. **บทบาท** — เลือกปฏิบัติการ เมนูการเงิน/ยอดรับชำระหาย แต่ผลเรียนยังดูได้ เลือกฝ่ายขาย + ปฏิบัติการเพื่อสาธิต union เป็นมุมมองเดโม ไม่ใช่ login จริง
10. **นำเข้า/Audit** — กลับผู้บริหาร ดาวน์โหลด CSV ตัวอย่างแล้วเลือกไฟล์ ตรวจพร้อม/ซ้ำ/ผิด กด Dry run 2 ครั้งก่อนนำเข้า ดู Audit before/after และ export
11. **ขอบเขต** — PEAK/2C2P/LINE/LearnDash ยังไม่ live ต้องต่อ Auth/DB/RLS/Queue/Secrets/Webhook และทำ UAT ก่อน Production
